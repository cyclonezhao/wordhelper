使役助动词

含义

1）让别人做某个动作

2）让事物成为某种状态

3）放任、听其自便

4）请求、允许

接续法和活用

読む　読ませる

起きる　起きさせる

くる　こさせる

する　させる

构成

学生が本を読む

先生が学生に本を読ませる。

親が心配する

私は親を心配させる。

先生は学生おしてお客さんにプリントを貸させる。

彼に話して子供達と一緒に川を渡らせる。

各活用形的用例

// 未然形

日本語学校では学生に英語を使わせない。

// 连用形

彼はいつも人を困らせます。

// 终止形

子供を一人で寝させる。

// 连体形

あの人にその仕事を続けさせることはできません。

// 假定形

私に作らせれば、もっと上手に作りますよ。

// 命令形

家のにいる人に戸を開けさせろ。

// 推量形

其他意思

表示放任，听其自便等意

表示请求，允许等意

私にも参加させてください。

しめる

被动助动词（118）

れる、られる

含义

1）承受别人动作

2）受到其他外力作用

接续

読む　読まれる

起きる　起きられる

くる　こられる

する　される

构成

// 不带宾语的被动句

警察は泥棒を捕まえた。

泥棒は警察に捕まえられた。

お母さんは子供を叱った

子供はお母さんに叱られた。

// 不带宾语的被动句

山田さんは彼に日本料理を進める。

彼は山田さんに日本料理を進められる。

// 主动句的宾语前有定语，被动句将定语变成主语，而宾语不变

スリは彼の財布をとった

彼はスリに財布をとられた。

// 不带主动者的被动句

オリンピックは四年ごとに行われる。

可能助动词(121)

れる、られる

含义

1）具有某种能力

2）允许实现某种动作

构成

物を食べる

物が食べられる

病人には物が食べられない。

可能动词

読む→読まれる→読める

かく　書かれる　書ける

話す　話させる　話せる

用五段动词构成可能句时，一般不用可能助动词，而直接用可能动词。

私にも日本語が少し話せる。

// 假定形

// 推量形

自发助动词（125）

れる、られる

1）接在与感情、情绪有直接关系的动词未然形后

2）表示自然发生或感情抑制不住的动作

3）接续法和活用和可能助动词一样

4）与自发助动词发生关系的动词为数不多，常见的有：思う、偲ぶ、思い出す、泣く、思いやる、考える、感じる、案じる

彼の厚意がしみじみ感じられる

この写真を見ると子供時代のことが偲ばれます。

外地の娘のことが案じられる。
